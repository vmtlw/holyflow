# Агенты HolyFlow

## Обзор

HolyFlow использует несколько агентов для выполнения различных задач в системе. Эти агенты работают как микросервисы, обеспечивая масштабируемость и отказоустойчивость системы.

## Агенты

### 1. Auth Agent (Агент аутентификации)

**Назначение**: Обработка всех операций аутентификации и авторизации.

**Функции**:
- Регистрация новых пользователей
- Аутентификация по логину/паролю
- Интеграция с OIDC провайдерами (OIDC, GitHub и др.)
- Восстановление пароля через email
- Генерация и проверка JWT токенов

**API Endpoints**:
- `POST /auth/register` - Регистрация
- `POST /auth/login` - Вход по логину/паролю
- `POST /auth/oidc/login` - Начало OAuth через OIDC
- `GET /auth/oidc/callback` - Callback от OIDC
- `POST /auth/forgot-password` - Восстановление пароля
- `POST /auth/reset-password` - Сброс пароля

### 2. User Agent (Агент пользователей)

**Назначение**: Управление профилями пользователей и их избранными песнями.

**Функции**:
- Получение и обновление профиля пользователя
- Управление списком избранных песен
- Хранение предпочтений пользователя

**API Endpoints**:
- `GET /users/me` - Получение профиля текущего пользователя
- `PUT /users/me` - Обновление профиля
- `GET /users/favorites` - Получение списка избранных песен
- `POST /users/favorites/{songId}` - Добавление песни в избранное
- `DELETE /users/favorites/{songId}` - Удаление песни из избранного

### 3. Song Agent (Агент песен)

**Назначение**: Управление коллекцией песен и связанными с ними медиафайлами.

**Функции**:
- Создание, чтение, обновление и удаление песен
- Хранение текстов песен и ритмических схем
- Загрузка и хранение MP3 файлов
- Загрузка и хранение обложек

**API Endpoints**:
- `GET /songs` - Получение списка песен
- `GET /songs/{id}` - Получение информации о песне
- `POST /songs` - Создание новой песни
- `PUT /songs/{id}` - Обновление информации о песне
- `DELETE /songs/{id}` - Удаление песни
- `POST /songs/{id}/upload-mp3` - Загрузка MP3 файла
- `POST /songs/{id}/upload-cover` - Загрузка обложки

### 4. Storage Agent (Агент хранилища)

**Назначение**: Управление файловым хранилищем (S3 совместимое).

**Функции**:
- Загрузка файлов в S3
- Генерация приватных URL для доступа к файлам
- Управление политиками доступа к файлам

**API Endpoints**:
- `POST /storage/upload` - Загрузка файла
- `GET /storage/{key}` - Получение URL для доступа к файлу

### 5. Email Agent (Агент электронной почты)

**Назначение**: Отправка электронных писем пользователям.

**Функции**:
- Отправка писем для подтверждения регистрации
- Отправка инструкций по восстановлению пароля
- Отправка уведомлений о важных событиях

**API Endpoints**:
- `POST /email/send` - Отправка письма

## Взаимодействие между агентами

Агенты взаимодействуют друг с другом через REST API и сообщения в очереди задач. Для внутреннего общения используется JWT токены для аутентификации.

## Развертывание

Каждый агент может быть развернут как отдельный Docker контейнер. Для оркестрации используется docker-compose или Kubernetes.

## Масштабирование

Агенты спроектированы как stateless сервисы, что позволяет легко масштабировать их горизонтально путем запуска нескольких экземпляров каждого агента.
